How to play

Works on Java and Bedrock. Pick a kit with /kit <name> before the match starts. You will have 2 minutes of invisibility to gather yourself, and then full PvP. Use Mushroom stews to heal hearts. A feast spawns around 20 minutes in, and a final End Game death match if the game is longer than 60 minutes. There is only one server for now with a minimum of 2 players to start the 5 minute countdown, and a max of 120 players. If you die, you will need to wait for the next match to play again.Your compass points at the nearest player.
